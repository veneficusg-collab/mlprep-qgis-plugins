LOCAL OUTPUT ORGANIZATION

Latest Runs/
  One reviewed, coherent official output bundle per workflow step.

Exploratory Runs/
  Sensitivity tests, alternate-input comparisons, profiling, and one-off
  analyses. These results must not be treated as production outputs.

Old run bundles should be archived outside the source workspace when they are
still needed. Sample Data, all run outputs, and trained models are excluded from
the source handoff package.
